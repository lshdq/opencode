## 2. Java 公共模块主业务影响

不适用：非Java。按通用规则核查稳定性、资源与一致性：

- **必需安全依赖**：ACL host失败阻止敏感写入符合批准的fail-closed方案；单次10秒、64KiB输出上限、kill后等close，脚本不创建后代；不建议不安全fallback。
- **调用放大**：SQLite一次acquisition一个host、最多四个固定文件路径；不在每条SQL或每行记录上执行。目录首次DACL设置可能由Windows传播继承，不把整个目录工作量虚称为O(1)。已私有目录只验证。
- **迁移一致性**：完整内容写后hardlink发布，冲突只忽略AlreadyExists；取消不删除其他赢家。外部强杀可能遗留私有temp，不能声称scoped finalizer可应对进程强杀，但不再制造空正式目标。
- **MCP生命周期**：每个owned root一个host/Job；WeakSet不强持有结束命令；唯一Job handle非继承、不允许breakaway，正常退出和异常退出均由进程teardown收容。保持原transport/spawner的scope、close及输出deadline，不另加无界队列/重试。
- **rg失败收敛**：最多三个候选、逐候选scope；现实现未加总提取超时，测试预算不等于生产超时保证。无现实必现挂起证据，不将理论场景升级为本轮缺陷。
- 本范围没有Redis、MQ或跨服务事务，不强行提出缓存/异步化改造。未发现新确认的生产线程/句柄泄漏、SQL放大或无界新增资源问题。
