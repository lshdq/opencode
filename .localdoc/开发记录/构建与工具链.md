3. **包装独立冻结安装，官方 build 使用 --skip-install**：上游 build.ts 默认会执行跨平台的 bun install 并可能触碰依赖声明；包装先执行 --frozen-lockfile，再传 --single --skip-web-ui --skip-install 和唯一 outdir。既保持官方构建链，又保护锁。

## ACL privateDirectory 协作：隔离脚本明确持有数据库目录（阶段5）
