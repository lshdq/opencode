## 当前实现
- Home/Session 不等待插件 ready；插件路由仍等待注册完成。启动提示移到右上角，不覆盖底部输入。
- launch file.list → location.get 远程 fallback 保留，移动到挂载后的首次默认 Location sync；本地插件目录仍根据客户端 cwd/global config 计算，目录发现 Promise 不阻塞渲染。
- Location info 与 catalog 失败分离：真正 info 失败保留官方恢复入口；catalog 失败在 App toast 显示并可 Retry，不替换 Session composer。客户端资源记录 error、保留 last-good，失败请求不缓存。
- 插件 shutdown 不 join loading，取消 trace 等待，关闭已开始的 activation；晚注册使用 activation 身份校验，晚到 cleanup 立即执行。setup 使用独立 Solid owner；异步注册的 keymap、data 订阅纳入 ownership。保持 reconcile 顺序并补 structural reload 的 last-good snapshot。
