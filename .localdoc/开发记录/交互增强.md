### 1. 权限模式
- 保持官方 `cli.json` 的 `session.permissions` 与 `--auto` 初始语义。
- `PermissionProvider` 内维护可选覆盖值：未手动切换时跟随官方来源；首次切换后当前实例全部标签共享覆盖，`--auto` 可切回 prompt，不写配置。

### 选定契约与实现
1. **提前 Enter**：必需 agent/model 尚未可用时不发送、不清草稿；就绪后需再次明确提交，不自动重发。未增加等待全部 Location 资源的屏障；稳定性代理已有提前重复 Enter 回归继续通过。
2. **准备阶段可取消**：保留编辑框中的原稿，按原有逻辑捕获 agent/model/variant/附件快照。Escape、文本编辑、清空、模式切换、路由/目录变化、标签停用、组件卸载和 TUI lifecycle shutdown 取消本次尚未发送的意图。
3. **发出后不撤销 admission**：在真正调用 prompt/shell/command 前才清草稿并记录历史；HTTP 一旦发出，不把本地 AbortSignal 传给运输层，不因后续编辑或退出取消可能已持久接收的内容。官方已发送请求仍遵循原有错误/事件协调。
4. **原生 Enter 延迟竞态**：实际回归发现准备期间再次 Enter 的 double-defer 回调可能在 Escape 后重新提交；现在准备中不再排入该回调，保留初始 IME double-defer 行为。
5. **await 边界**：getDirectory 内的 Session/Location/worktree await、Session create/environment、prepareAgent 的 sync/switchAgent、switchModel、revert commit、synthetic admission 后均再次核查取消与来源意图。已开始的服务端副作用不做反向删除或回滚；取消只阻止后续步骤。
6. **新会话不抢路由**：保留官方 optimistic Session record，但发送成功后才导航；仅当来源 Prompt 未销毁/停用、未导航或编辑时导航。新 Session 已创建而发送取消时可留下空 Session，不强行删除服务器数据。
7. **失败与草稿**：准备失败保留原稿；已发请求失败仅在来源仍有效且空编辑框未被改动时恢复快照。用户新草稿优先；导航/退出使用已有 draft stash，不由迟到回调写回别的页面。
8. **队列与权限保持**：继续调用官方 data.session.prompt 的 per-session admission 链，不重排已发请求，不改变 steer/queue payload；shell/command 仍使用各自官方端点及权限路径。取消排队中的第二次本地发送不撤销第一条已发 admission。
9. **synthetic**：保持 `resume:false`。成功提交的 editor context 按同一 selection 身份标记已发送；取消后不发送对应 user prompt，也不回滚已经成功的 synthetic。

## R-03 阶段5完成：应用层 owned undo/redo

### 授权方案与实际实现
- 主代理明确 Auto 选择“不fork OpenTUI，应用层拥有历史”，本轮据此继续实现，不再请求用户确认。决策与16 MiB子方案记入同一决策文件 DEC-013，取代 DEC-011 的原生checkpoint计量。
- `src/component/prompt/undo.ts` 改为独立逻辑历史：before完整文本/caret/metadata，执行原生当次编辑后清其history；undo/redo直接用底层setText还原目标状态，**不调用原生undo/redo，不读取/比较内部checkpoint**。公开canUndo/canRedo只读取应用栈。
- 每个公开mutator一次逻辑编辑；forward Delete即便EOF也保留一条删除意图，普通forward不再有两个内部空步骤。其他真正no-op不丢redo，无效range的TS mark副作用恢复为本次调用前当前metadata。同文replace保留metadata变化语义；选择替换仍是delete+insert两步，F02原测试无需改动。
- setText/owned/clear清逻辑历史与marks；clearHistory只清历史而保留当前payload。replace与restore均使用setText的单一内存槽，避免OpenTUI replaceText的TS `_textBytes` 数组持续保留旧全文。
- 历史最多256逻辑步，另有16 MiB逻辑保留预算。使用有界全文快照而非逆patch；文本及metadata字符串进入有界canonical池，**实际引用也共享**，不是只在预算计算里去重。淘汰完整最旧undo/远端redo，reset/cleanup清池，不跨缺口恢复。
- 读取历史文本通过公开RenderLib获取真实byteSize，绕过EditBuffer.getText的1 MiB输出截断；自动测试检查超过此大小的末尾END和caret恢复。
- 捕获显示列而非UTF-16下标；undo/redo清过期选区，恢复caret；连续纵向导航记录anchor/有效行差，恢复后下一次上下移动保留desired-column，覆盖逻辑行、视觉行和软换行。横向/显式定位/鼠标定位中断旧导航链。
- 锁定TS extmarks适配：初始/清空/cleanup清自有history，绑定期间禁用其saveSnapshot；保留实时mark跟随编辑。仅用两个TS成员名，未读原生私有布局、未改依赖或node_modules。公开接口没有对应禁用入口，升级需按契约文档核查此适配。
