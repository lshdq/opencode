# 需求：构建使用上游版本

## 背景与目标
Windows 构建直接使用已合入上游的原版本号，取消本地 `.wN` 后缀。

## 功能描述
### 核心功能
- 版本来源保持为 `git merge-base HEAD upstream/dev` 处的 `packages/opencode/package.json` version。
- `build-win.ps1` 删除 WinVersion 参数和后缀拼接，将原版本传入 OPENCODE_VERSION。
- win-adapt skill 同步更新版本规则、示例和部署校验（X.Y.Z）。
### 边界与约束
- 本次为构建规则修改，不执行上游合并、完整产品构建或实际部署。
- 保留现有构建参数、模型缓存设置及版本化部署与哈希校验。
- 历史修复记录中旧版本号保留。

## 输入输出
输入为已合入上游版本，例如 1.18.11；输出构建版本为 1.18.11，重复构建保持相同版本。

## 非功能需求（性能/安全/兼容性）
PowerShell 7 语法有效；删除 WinVersion 属于已批准参数变更；版本读取失败不得以空版本继续构建。

## 依赖
Git、PowerShell 7、现有 Bun 构建入口。

## 验收标准
1. skill 与脚本均不再要求或生成 `.wN`。
2. 使用 merge-base 版本，非 upstream/dev 尚未合入的最新版本。
3. OPENCODE_VERSION 为原版版本号，重复构建不递增。
4. 部署校验接受 1.18.11，拒绝 1.18.11.w4。
5. 语法检查、独立测试和代码审查通过。

## 已批准方案与模式
用户已确认上述范围及 Auto 模式。仅修改 `.opencode/skills/win-adapt/SKILL.md` 和 `packages/opencode/script/build-win.ps1`，测试资料位于 .localdoc。
