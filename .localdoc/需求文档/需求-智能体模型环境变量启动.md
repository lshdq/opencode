# 需求：智能体模型环境变量启动

## 背景与目标

全局 OpenCode 配置中的开发子智能体模型和 variant 当前为固定值。将这些值改为从启动进程环境变量读取，并提供一个 Windows CMD 启动脚本集中设置当前值，便于后续仅修改脚本即可切换模型配置。

## 功能描述

### 核心功能

- `dev-fast`、`dev-standard`、`dev-deep` 的 `model` 共用环境变量 `OPENCODE_DEV_MODEL`。
- 三个智能体的 `variant` 分别读取 `OPENCODE_DEV_FAST_VARIANT`、`OPENCODE_DEV_STANDARD_VARIANT`、`OPENCODE_DEV_DEEP_VARIANT`。
- 在全局 OpenCode 配置目录创建 `opencodeGpt.cmd`。
- 启动脚本将环境变量设置为配置修改前的当前值：模型为 `openai/gpt-5.6-sol`，variant 依次为 `medium`、`high`、`xhigh`。
- 启动脚本通过 `--model` 将 `OPENCODE_DEV_MODEL` 同时指定为交互式 TUI 的主模型。
- 启动脚本透传调用参数和 OpenCode 退出码。

### 边界与约束

- 启动脚本面向启动交互式 OpenCode TUI，透传参数按 TUI 参数处理，不保证兼容 `debug` 等子命令。
- 不为主模型指定 variant，因为三个开发子智能体使用不同 variant。
- 不修改 OpenCode 产品源码。
- 环境变量只在启动脚本的局部环境中生效，不污染调用脚本的终端环境。
- 直接运行 `opencode` 且未预设相关环境变量时，不保证三个开发子智能体配置可用。

## 输入输出

- 输入：调用 `opencodeGpt.cmd` 时提供的可选 TUI 参数。
- 输出：以指定主模型启动的 OpenCode TUI；开发子智能体使用环境变量解析后的模型和 variant。
- 配置文件：`C:\Users\lshdq\.config\opencode\opencode.jsonc`。
- 启动脚本：`C:\Users\lshdq\.config\opencode\opencodeGpt.cmd`。

## 非功能需求（性能/安全/兼容性）

- 使用 OpenCode 原生 `{env:VAR}` 配置替换语法。
- CMD 脚本兼容当前 Windows 环境。
- 脚本不持久化修改用户级或系统级环境变量。
- 保留全局配置中未涉及的全部字段。

## 依赖

- `opencode` 命令已加入 `PATH`。
- 当前 OpenCode 版本支持配置中的 `{env:VAR}` 替换和 TUI `--model` 参数。

## 验收标准

- 三个开发子智能体的六个配置字段均改为环境变量引用。
- 脚本设置一个共享模型变量和三个独立 variant 变量，值与修改前一致。
- 脚本启动命令显式包含 `--model "%OPENCODE_DEV_MODEL%"`。
- 脚本透传 TUI 参数及退出码。
- `opencode debug config` 在设置相同环境变量后可解析出预期 agent 配置。
- 脚本执行非交互帮助或版本参数时成功返回，证明命令和参数传递路径有效。
