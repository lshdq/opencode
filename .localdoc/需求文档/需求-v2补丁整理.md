## 功能描述
### 核心功能
1. 插件安装/setup 慢或挂起时仍能编辑 TUI 输入；退出不等待任意第三方初始化完成，晚到贡献必须清理。
2. 真正 Location 错误与单项 model/provider/MCP/skill 等资源失败分离；局部失败不替换 Session 输入框，保留草稿并可重试。首屏前非必要 Location 探测后台化。提交只等待必需依赖，取消、编辑、导航及退出不产生迟到重复提交。
3. Windows rg 冷安装可靠解压，隔离 PSModulePath，覆盖 pwsh/PS5.1、空格/中文/单引号路径。
4. Windows owner-only 敏感文件权限按当前 SID 保护；覆盖 service 密码配置、注册临时文件/原子替换，以及本地凭据 SQLite 和 sidecar 的适用生命周期。不得递归收紧任意用户自定义数据库父目录。失败不得把当前用户锁死。
5. 保留四项交互增强：权限模式一键切换；Ctrl+X 条件剪切；助手创建时间显示开关；auto 独立语义色。
6. 权限初始值来自官方 cli.json session.permissions/--auto；手动切换为当前 TUI 实例临时覆盖（涵盖其标签），可由 --auto 切回 prompt，不自动写回设置；deny 不变。run 使用官方 --auto，不增加 auto_approve schema。
7. 剪切仅针对聚焦、可编辑、有效选区；无选区保留 Ctrl+X leader；剪贴板失败不删文本，异步完成不得误删变化后的内容。覆盖粘贴占位符和撤销。
8. 时间戳显示消息创建时刻，覆盖跨日、窄屏和持久显示开关；auto 色具备 light/dark/custom-theme fallback。
9. Windows spawn/kill watchdog、MCP orphan、fs busy retry、Git null device、terminal/clipboard 必须先验证当前基线，已覆盖的只保留回归证据，不重复补丁。普通 shell 正常退出后允许后代存活的官方语义必须保留。
10. 新 Windows 构建/CI 使用 packages/cli，固定基线版本，记录构建参数/哈希；独立数据与服务环境冒烟后部署版本化制品，不自动激活默认 exe。

### 边界与约束
- 原 win-adapt 工作区和已安装默认程序保持可作对照。用户允许暂缺 LSP，不恢复旧 runtime。
- 采用官方 lazy imports、LocationServiceMap、config/reference discovery、PowerShell 参数、post-exit output deadline、模型 snapshot/刷新链。
- snapshot:false 的最强离线策略仅验证，不默认改变官方 populate 契约。
- 不提交、不推送，除非用户后续明确要求。
- 每项补丁附带台账、回归依据和退役条件。

## 输入输出
输入：官方固定提交、旧 fork 实现和测试、独立 Windows 测试环境。
输出：v2 工作树改动、配置迁移说明、补丁台账、独立测试/审查报告、可追溯版本化制品。

## 非功能需求（性能/安全/兼容性）
- 非 Windows 平台保持官方行为，公共代码变更需对应验证。
- 测试 config/data/state/cache 及服务注册隔离，核对实际服务进程身份；不能连接/替换现有日常服务。
- 性能区分 cold/warm、service running/not running；实测数据不足不得声称优化百分比。
- 自动更新不得静默将 fork 替换为官方；测试历史数据只使用副本，迁移与回滚包含数据。
- 代码遵守最新根目录和包 AGENTS；Effect API 以当前依赖源码为准。
