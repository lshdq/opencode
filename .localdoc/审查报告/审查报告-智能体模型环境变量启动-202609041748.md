## 残余风险及测试缺口

1. 未实际启动交互式 TUI，也未发起三个开发子智能体的真实模型请求；当前证据由配置解析、CLI/TUI 源码调用链和非交互参数测试组合提供。因此，运行时 provider 可用性、账号权限及各 variant 是否被远端模型接受仍取决于外部环境。
2. 未设置四个环境变量而直接运行 `opencode` 时，`{env:...}` 会被替换为空字符串；三个开发 agent 可能不可用。这是需求文档明确接受的启动方式约束，使用者必须从 `opencodeGpt.cmd` 启动或自行预设变量。
3. 参数透传测试只覆盖 `--help`、`--version` 和非法参数，未覆盖带空格、引号或 CMD 元字符的 `--prompt` 等复杂 TUI 参数。当前实现严格采用已批准的 `%*` 方案，但此类输入仍缺少证明性测试。
4. 脚本依赖 `PATH` 中可解析的 `opencode` 命令；命令缺失或 PATH 指向非预期版本时会失败。该依赖已在需求文档中声明。
