### DEC-002: 修复迁移返回值的字面量推断
- 阶段：方案设计
- 背景：Effect Schema 转换函数将固定字符串推断为普通 `string`，导致 `packages/app` 类型检查失败。
- 可选方案：使用类型断言；调整 Schema/转换返回值以保留字面量；放宽 schema 类型。
- 最终选择：在转换返回值中保留受 schema 约束的字面量类型，不放宽 schema。
- 选择理由：保持运行时行为和严格 schema 约束，避免不安全断言和数据契约变宽。
- 影响：只改变 TypeScript 类型推断，不改变持久化数据格式。
