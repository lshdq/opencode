# 测试用例：开发任务复杂度模型路由

## 测试范围

验证全局 Agent 定义、模型配置、build/plan 调用权限及 `dev-workflow` 阶段 5、6、7 的复杂度路由规则。

## 用例列表

### TC-001: 全局配置可加载
- 前置条件：全局 `opencode.jsonc` 已修改。
- 操作步骤：执行 OpenCode 配置加载或模型列表命令。
- 预期结果：命令成功，不出现 `ConfigInvalidError`。
- 优先级：P0

### TC-002: 三档模型和思考深度有效
- 前置条件：三个模型均存在于本机模型目录。
- 操作步骤：读取详细模型元数据并核对 Agent 配置。
- 预期结果：三个模型存在，且分别支持 `low`、`medium`、`high` variant。
- 优先级：P0

### TC-003: 三个 Agent 定义有效
- 前置条件：三个 Agent 文件已创建。
- 操作步骤：检查 frontmatter 和配置合并结果。
- 预期结果：三个 Agent 均为 `subagent`，具有描述，且禁止继续调用 Task。
- 优先级：P0

### TC-004: build 可以调用三档 Agent
- 前置条件：全局配置已加载。
- 操作步骤：评估 `build.permission.task` 对三个 Agent 名称的规则。
- 预期结果：三个结果均为 `allow`。
- 优先级：P0

### TC-005: plan 不能调用三档 Agent
- 前置条件：全局配置已加载。
- 操作步骤：评估 `plan.permission.task` 对三个 Agent 名称的规则。
- 预期结果：三个结果均为 `deny`，Task 描述不会向 plan 展示它们。
- 优先级：P0

### TC-006: 阶段5按子任务路由
- 前置条件：`dev-workflow` 已修改。
- 操作步骤：检查阶段 5 的执行规则和委派 prompt 要求。
- 预期结果：每个开发、修复子任务独立分级并委派给对应 Agent。
- 优先级：P0

### TC-007: 阶段6按子任务路由且保持独立测试
- 前置条件：`dev-workflow` 已修改。
- 操作步骤：检查阶段 6 的 Agent 选择、独立会话和 `test-workflow` 加载规则。
- 预期结果：每个测试子任务独立分级，不复用开发会话，测试约束完整保留。
- 优先级：P0

### TC-008: 阶段7按子任务路由且保持独立审查
- 前置条件：`dev-workflow` 已修改。
- 操作步骤：检查阶段 7 的 Agent 选择、独立会话和 `code-review` 加载规则。
- 预期结果：每个审查子任务独立分级，不复用开发或测试会话，审查范围约束完整保留。
- 优先级：P0

### TC-009: 非目标 Agent 行为不变
- 前置条件：全局配置已修改。
- 操作步骤：检查原有 `general`、`explore` 和 debate Agent 配置。
- 预期结果：原有 Agent 未被删除或覆盖。
- 优先级：P1

## 测试命令

```powershell
opencode models openai --verbose
opencode debug config
```

如当前 CLI 不提供 `debug config`，使用 JSONC 解析和 OpenCode 启动级只读命令完成等价验证。
