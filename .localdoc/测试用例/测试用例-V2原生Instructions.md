# 测试用例：V2 原生 Instructions

## 测试范围

V2 配置来源解析与指令生命周期、全局配置迁移，含 V1 相对规则兼容与 URL 读取。

## 用例列表

### TC-001: 相对 glob 向上匹配与顺序
- 前置条件：会话目录及项目根各有 `.opencode/AGENTS.md`。
- 操作步骤：配置 `instructions: [".opencode/AGENTS.md"]`，加载指令。
- 预期结果：近到远各出现一次，项目外文件不进入上下文。
- 优先级：P0

### TC-002: 本地绝对 glob、家目录与重复去重
- 前置条件：存在匹配文件，配置多个来源指向同一文件且与自动发现路径重合。
- 操作步骤：加载并检查模型请求。
- 预期结果：绝对 glob 与 `~/` 正确解析，路径只注入一次，顺序稳定。
- 优先级：P0

### TC-003: HTTP(S) URL 来源
- 前置条件：隔离 HTTP 测试服务返回规则文本。
- 操作步骤：配置 URL，发起模型请求，改变响应再请求。
- 预期结果：首次和更新规则被纳入上下文；超时/失败不会误删已有值；签名 URL 的凭据/查询参数不会被日志、模型可见来源说明或可读持久化来源字段泄漏，不同 URL 不误合并。
- 优先级：P0

### TC-004: 文件创建、编辑、删除及配置变化
- 前置条件：有活动会话和已加载规则。
- 操作步骤：依次创建、编辑、删除文件以及修改 instructions 数组。
- 预期结果：后续模型请求收到对应更新；短暂读取或目录遍历故障保留上次值，重启后已有会话也不误撤销，真实删除仍撤销；反复替换配置来源或遇 URL/文件读取失败时旧 watcher 退订，新来源仍可更新。
- 优先级：P0

### TC-005: 会话移动及持久化边界
- 前置条件：两个项目有不同规则。
- 操作步骤：移动会话，触发后续请求；验证压缩/回退后的指令重载行为。
- 预期结果：目标规则生效、旧规则正确撤销，状态链路不被插件临时文本绕开。
- 优先级：P1

### TC-006: 全局配置迁移
- 前置条件：全局配置注册了 `./extensions/server`。
- 操作步骤：迁移后使用隔离服务及全局配置测试。
- 预期结果：instructions 配置生效、外部插件不再注册，其他设置保持，三个 debate agent 的旧温度补丁不再作为验收条件。
- 优先级：P0

## 测试命令

- 在 `packages/core`：`bun test test/instruction-discovery.test.ts test/instruction-state.test.ts`（按新增测试调整路径）；`bun typecheck`。
- 在全局配置仓库：`bun run check`、与迁移相关的隔离集成测试（使用本工作区构建的 V2 服务）。
- 在仓库根目录：`bun run check`。

## 测试场景分类

框架代码（Core、配置、会话指令）及通用（全局配置与隔离集成验证）。
