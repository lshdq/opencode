# 测试用例：V2 Fork 开发技能与 Windows 部署命名

## 测试范围

技能内容、动态上游版本解析、Windows 构建和单文件部署路径、构建与冒烟验证。

## 用例列表

### TC-001: 技能更名与 V2 分支引用
- 前置条件：项目本地技能目录可读。
- 操作步骤：核对新 skill frontmatter 与目录名，检查相关技能分支、命令、构建路径，全文搜索旧描述。
- 预期结果：`fork-development` 可发现；旧 V1 指令不存在；合并 skill 指向 `v2` 与 `upstream/v2`。
- 优先级：P0

### TC-002: 构建版本来自已合入上游
- 前置条件：本地 `upstream/v2` 引用存在。
- 操作步骤：验证 merge-base 对应的上游包版本，检查构建元数据、编译版本及冒烟校验路径。
- 预期结果：随已合入上游变化读取版本；未合入的上游新提交不会改变当前构建版本；不硬编码 `2.0.12`。
- 优先级：P0

### TC-003: 部署只复制带分钟时间戳的单个 exe
- 前置条件：隔离冒烟通过，指定已存在的非生产部署目录。
- 操作步骤：运行部署逻辑或具有相同效果的针对性测试，检查部署目录内容和 exe 文件名。
- 预期结果：只新增 `opencode-<版本>-<YYYYMMDDHHmm>.exe`；exe 哈希与构建产物一致，不创建版本子目录或复制元数据。
- 优先级：P0

### TC-004: 同分钟目标冲突
- 前置条件：目标文件名已存在。
- 操作步骤：再次尝试部署。
- 预期结果：失败且原文件不变。
- 优先级：P0

### TC-005: 构建选项与失败保护
- 前置条件：Windows 构建工具链可用。
- 操作步骤：检查或执行 `-BuildOnly`、`-NoDeploy`、冒烟失败及默认流程。
- 预期结果：只构建不部署；冒烟通过但 NoDeploy 不部署；冒烟失败禁止部署；默认部署不激活日常 exe。
- 优先级：P1

### TC-006: 改名后的可执行文件启动
- 前置条件：非生产临时部署目录有构建产物。
- 操作步骤：对改名后的 exe 执行 `--version`；必要时验证其独立运行。
- 预期结果：输出与上游构建版本一致，且不使用共享日常服务。
- 优先级：P1

## 测试命令

- 从 `packages/cli` 运行：`bun test script/windows-build.test.ts`；按必要范围执行 Windows 集成验证。
- 从仓库根目录运行：`bun run check`。
- 文档检查：对涉及的 skill 和 `docs/v2-Windows构建与迁移.md` 检查旧引用、命令和命名示例。

框架代码 + 文档验证。
