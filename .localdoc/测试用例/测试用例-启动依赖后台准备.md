# 测试用例：启动依赖后台准备

## 测试范围
TUI 首屏、后台配置/插件准备、消息提交屏障、取消/退出、权限模式、恢复/自动发送、故障处理。

## 用例列表
### TC-001: 慢安装时界面可交互
- 前置条件：配置或插件初始化受可控 deferred 阻塞。
- 操作步骤：启动真实 TUI 测试宿主，安装未完成时输入文字并打开基础界面操作。
- 预期结果：主页/输入框已渲染，草稿可编辑，准备提示可见。
- 优先级：P0
### TC-002: 提交等待与去重
- 前置条件：初始化未就绪，已有草稿。
- 操作步骤：连续提交，随后释放初始化。
- 预期结果：就绪前无请求，就绪后恰好一次发送，认证/模型/工具及权限已准备。
- 优先级：P0
### TC-003: 等待取消与退出
- 前置条件：提交正等待初始化。
- 操作步骤：分别取消、卸载/退出、切换会话后释放初始化。
- 预期结果：取消或销毁的提交不发送，保留合适的草稿，无迟到 UI 更新或泄漏。
- 优先级：P0
### TC-004: 准备失败
- 前置条件：准备流程可控失败。
- 操作步骤：等待中抛出安装/配置/插件错误。
- 预期结果：按既有可选插件失败策略处理；不可恢复准备失败明确反馈、草稿保留、提交锁释放，无永久等待。
- 优先级：P0
### TC-005: 缓存命中和无插件
- 前置条件：缓存可用或无外部插件。
- 操作步骤：启动并发送。
- 预期结果：正常启动和提交，没有人为等待或重复初始化。
- 优先级：P1
### TC-006: 自动批准配置
- 前置条件：后台配置 auto_approve=true/false，CLI auto 分别开启/关闭。
- 操作步骤：准备前提交；另测准备期间用户主动切换权限模式。
- 预期结果：首条请求前权限配置正确；CLI 显式 auto 优先；用户手动选择不被迟到配置覆盖。
- 优先级：P0
### TC-007: 恢复会话与自动发送
- 前置条件：--prompt、--session、--continue、--fork 或 attach。
- 操作步骤：慢初始化后释放，观察恢复/分叉和初始消息。
- 预期结果：目标正确，自动消息只发送一次，等待期间不误报缺少 agent/model。
- 优先级：P0
### TC-008: 插件生命周期和配置顺序
- 前置条件：插件提供配置、模型、工具或 TUI 路由。
- 操作步骤：慢初始化、就绪以及初始化未完成时退出。
- 预期结果：使用前完成初始化，顺序稳定，插件路由适当加载，退出清理正确。
- 优先级：P0
