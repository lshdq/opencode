## 测试命令
- 根目录：bun run check（最新项目规范的 lint/typecheck 总入口，不是根测试）。
- 各受影响包 packages/tui、theme、client、core、util、cli：bun typecheck。
- packages/tui：bun test --timeout 30000 test/app-lifecycle.test.tsx test/plugin-source.test.ts test/cli/tui/data.test.tsx；新增功能测试由对应开发记录确切路径。
- packages/client：bun test --timeout 30000 test/solid-data.test.ts。
- packages/theme：bun test test/theme.test.ts。
- packages/core：bun test --timeout 30000 test/ripgrep.test.ts test/effect/cross-spawn-spawner.test.ts test/mcp.test.ts；ACL/冷安装新增测试路径按实际追加。
- packages/cli：bun test --timeout 30000 test/service.test.ts；构建使用新增 Windows wrapper（默认先 smoke 再版本化部署）。
- 禁止仓库根 bun test；禁止未隔离的 dev:live；Bun 使用匹配 1.4.2 的 D 盘工具链。

## 测试场景分类
通用。网络/交互终端/非 Windows runner 不具备时，记录未执行原因，继续其余测试与审查。
