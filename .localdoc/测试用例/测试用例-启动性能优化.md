# 测试用例：启动性能优化

## 测试范围

win-adapt 分支上的启动性能优化改动：命令懒加载、tui.ts 并行化、git discover 合并、references 解耦（纯函数）、location bundle 预热。
涉及包：`packages/core`、`packages/opencode`、`packages/tui`。

## 用例列表

### TC-001: 命令懒加载后 --version/--help 行为不变
- 前置条件：已构建的新二进制
- 操作步骤：运行 `opencode --version`、`opencode --help`、`opencode mcp --help`、`opencode run --help`
- 预期结果：输出与旧版一致（版本号、命令列表、参数说明无缺失）
- 优先级：P0

### TC-002: --version 热启动耗时达标
- 前置条件：新二进制部署后（路径固定），磁盘缓存热
- 操作步骤：连续 5 次 `Measure-Command { opencode --version }`
- 预期结果：中位数 <250ms
- 优先级：P0

### TC-003: git discover 合并后仓库识别正确
- 前置条件：普通 git 仓库、git worktree、非 git 目录（如 %TEMP% 子目录）
- 操作步骤：在三类目录分别启动 opencode（或运行触发行列实例的命令，如 `opencode debug config`），检查日志中 project 识别
- 预期结果：project ID 与旧版一致；非 git 目录回退 global；worktree 正确识别 worktree 根与 common dir
- 优先级：P0

### TC-004: references 纯函数路径推导与旧实现等价
- 前置条件：含 local 绝对路径、`~/` 展开、相对 config 文档目录、git 仓库（含 branch）、非法别名（含 `/`、空格、空串）的 references 配置
- 操作步骤：单元测试对比纯函数输出与 config-reference 插件 + Reference.list 旧路径输出
- 预期结果：名称集合与路径逐一相等；git 引用路径为 `Repository.cachePath` 结果；非法别名被过滤
- 优先级：P0

### TC-005: agents 列表与权限白名单不回归
- 前置条件：新二进制 + 用户现有配置（5 个 reference）
- 操作步骤：TUI 打开后查看 agent 列表（build/plan/dev-fast/dev-standard/dev-deep）；让 build agent 读取 `~/.config/opencode/references/code-review-base/guide.md`
- 预期结果：agent 列表完整；读取 reference 目录内文件不弹 external_directory 确认
- 优先级：P0

### TC-006: 启动时间线达标（无头）
- 前置条件：新二进制，工作目录 D:\works\thirdparty\opencode
- 操作步骤：`--print-logs --log-level DEBUG` 无头运行 25s 后终止，分析日志时间线
- 预期结果：首个 config.get RPC 返回 <1s；"booting location services" 首次出现在 agents RPC 完成之后（后台预热）；无 3.7s 阻塞空窗
- 优先级：P0

### TC-007: snapshot 功能正常
- 前置条件：TUI 打开一个 session
- 操作步骤：让 agent 编辑一个文件，然后 revert
- 预期结果：diff 显示正确、revert 成功
- 优先级：P1

### TC-008: 首个 prompt 性能不退化
- 前置条件：TUI 打开（ready）后立即输入 prompt
- 操作步骤：ready 后 1s 内发送一个简单 prompt
- 预期结果：响应时间与旧版相当（预热并发去重生效，无双编译）
- 优先级：P1

### TC-009: taskbar-flash 插件生效
- 前置条件：新二进制
- 操作步骤：正常运行 TUI，触发任务栏闪烁条件
- 预期结果：插件功能与旧版一致（服务端加载失败的 ERROR 日志仍存在属已知上游问题，不算回归）
- 优先级：P2

### TC-010: typecheck 与现有测试
- 前置条件：源码改动完成
- 操作步骤：`bun typecheck`（packages/core、packages/opencode、packages/tui 各自目录内）；`bun test`（packages/opencode，不得从 repo 根运行）
- 预期结果：全部通过
- 优先级：P0

## 测试命令

```powershell
# typecheck（各包目录内）
cd packages/core; bun typecheck
cd packages/opencode; bun typecheck
cd packages/tui; bun typecheck

# 单元/集成测试（包目录内，禁止 repo 根）
cd packages/opencode; bun test
cd packages/core; bun test

# 性能实测
Measure-Command { & "D:\Program\opencode\opencode.exe" --version }
# 无头 TUI 时间线
# Start-Process opencode --print-logs --log-level DEBUG → 25s 后终止 → 分析 stderr 日志时间戳
```
