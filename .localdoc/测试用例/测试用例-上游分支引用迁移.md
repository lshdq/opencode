# 测试用例：上游分支引用迁移

## 测试范围

验证上游分支从 `v2` 迁移到 `dev` 后，CI、Windows 构建基线、测试 fixture、技能文档和上游差异命令的一致性；确认产品/API 的其他 `v2` 语义未被误改。

## 用例列表

### TC-001: 活动上游引用扫描

- 前置条件：完成引用迁移。
- 操作步骤：在有效代码、CI、技能和跟踪文档中检索 `upstream/v2`、`refs/remotes/upstream/v2` 及官方上游 `v2` 分支描述。
- 预期结果：无活动命中；未跟踪 `.localdoc` 历史记录不纳入本用例。
- 优先级：P0

### TC-002: Windows 构建基线专项测试

- 前置条件：仓库依赖可用。
- 操作步骤：在 `packages/cli` 执行 `bun test script/windows-build.test.ts`。
- 预期结果：构建基线、共同祖先版本、缺失远程引用和工作区版本相关测试通过。
- 优先级：P0

### TC-003: CI 引用静态核对

- 前置条件：读取 `.github/workflows/build-windows.yml`。
- 操作步骤：核对 fetch refspec、merge-base 输入和错误消息。
- 预期结果：均指向 `dev` / `upstream/dev`，不依赖 `upstream/v2`。
- 优先级：P0

### TC-004: 仓库检查

- 前置条件：专项测试通过。
- 操作步骤：从仓库根目录执行 `bun run check`。
- 预期结果：检查通过。
- 优先级：P1

## 测试命令

```text
cd packages/cli
bun test script/windows-build.test.ts

cd ../..
bun run check
```

## 测试场景分类

框架代码 / 通用 / 文档验证。
