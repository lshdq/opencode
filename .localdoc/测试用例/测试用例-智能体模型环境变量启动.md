# 测试用例：智能体模型环境变量启动

## 测试范围

验证全局 OpenCode 配置的环境变量替换、三个开发子智能体的解析结果，以及 Windows CMD 启动脚本的模型参数、参数透传和退出码行为。

## 用例列表

### TC-001: 验证环境变量配置引用
- 前置条件：全局配置修改完成。
- 操作步骤：读取 `opencode.jsonc` 中三个开发子智能体的 `model` 和 `variant`。
- 预期结果：三个 `model` 均为 `{env:OPENCODE_DEV_MODEL}`；三个 `variant` 分别引用各自约定的环境变量。
- 优先级：P0

### TC-002: 验证解析后的智能体配置
- 前置条件：在独立 CMD 进程中设置四个约定环境变量。
- 操作步骤：执行 `opencode debug config` 并检查三个开发子智能体的解析结果。
- 预期结果：模型均为 `openai/gpt-5.6-sol`，variant 分别为 `medium`、`high`、`xhigh`。
- 优先级：P0

### TC-003: 验证启动脚本当前值
- 前置条件：`opencodeGpt.cmd` 已创建。
- 操作步骤：检查脚本内四个环境变量赋值。
- 预期结果：赋值与修改前配置完全一致，并使用 `setlocal` 限制变量作用域。
- 优先级：P0

### TC-004: 验证主模型参数与参数透传
- 前置条件：`opencode` 命令可执行。
- 操作步骤：通过脚本传入非交互帮助或版本参数。
- 预期结果：脚本调用包含 `--model "%OPENCODE_DEV_MODEL%"`，参数被 OpenCode 接收并正常返回。
- 优先级：P1

### TC-005: 验证退出码透传
- 前置条件：`opencodeGpt.cmd` 已创建。
- 操作步骤：调用可确定退出状态的非交互参数并检查脚本退出码。
- 预期结果：脚本退出码与被调用的 `opencode` 命令一致。
- 优先级：P1

## 测试命令

```powershell
cmd.exe /d /c "set OPENCODE_DEV_MODEL=openai/gpt-5.6-sol&&set OPENCODE_DEV_FAST_VARIANT=medium&&set OPENCODE_DEV_STANDARD_VARIANT=high&&set OPENCODE_DEV_DEEP_VARIANT=xhigh&&opencode debug config"
cmd.exe /d /c "\"%USERPROFILE%\.config\opencode\opencodeGpt.cmd\" --help"
```
