# 测试用例：上游同步

## 测试范围

验证上游同步的 Git 状态、合并完整性、Windows 适配保留情况、类型正确性与远端推送结果。

## 用例列表

### TC-001: 校验远端与目标分支

- 前置条件：仓库可正常执行 Git 命令。
- 操作步骤：检查 `git remote -v`、当前分支及工作区状态。
- 预期结果：`upstream` 和 `origin` 地址正确，当前分支为 `win-adapt`，合并前工作区干净。
- 优先级：P0

### TC-002: 校验上游合并完整性

- 前置条件：已完成 `upstream/dev` 合并。
- 操作步骤：检查冲突状态、提交图及 `win-adapt..upstream/dev` 的提交差异。
- 预期结果：不存在未合入的上游提交，不存在未解决冲突。
- 优先级：P0

### TC-003: 校验 Windows 适配保留情况

- 前置条件：合并冲突已处理。
- 操作步骤：检查与 fork 自有提交重叠的文件和 `win-adapt` 标记，复核冲突解决结果。
- 预期结果：Windows 适配未被上游变更覆盖或删除。
- 优先级：P0

### TC-004: 执行类型检查

- 前置条件：Bun 及项目依赖可用。
- 操作步骤：在仓库根目录执行 `bun turbo typecheck`。
- 预期结果：命令成功退出，无类型错误。
- 优先级：P0

### TC-005: 校验推送结果

- 前置条件：类型检查成功并已推送。
- 操作步骤：检查本地 `win-adapt` 与 `origin/win-adapt` 的跟踪状态。
- 预期结果：本地与 fork 远端同步，未向 `upstream` 推送。
- 优先级：P0

## 测试命令

```bash
bun turbo typecheck
git status --short --branch
git log --oneline win-adapt..upstream/dev
```
