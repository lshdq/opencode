## 概述

依据《opencode-Windows缺陷清单》（`../opencode-Windows缺陷清单.md`）系统性修复 Windows 平台缺陷，共完成 **13 项**（严重 2、高 3、中 6、低 2），覆盖 P0–P3 优先级；另有 3 项低优先级项经评估不做修改（见文末）。

## 严重（影响核心功能）

### S1 — archive.ts 改用 pwsh + 安全传参
- **问题**：LSP 解压使用 `powershell`（5.1，中文 Windows 下 GBK 编码），且路径拼入单引号字符串，遇含单引号路径会命令断裂或注入
- **方案**：探测优先 `pwsh`（回退 `powershell`）；改用 `-LiteralPath` 并通过**环境变量**传递路径，彻底消除引号/注入问题
- **文件**：`packages/opencode/src/util/archive.ts`
- **验证**：含单引号路径的 zip 解压实测通过

### S2 — V2 bash tool 补齐 PowerShell 调用分支
- **问题**：V2 core bash tool 在 Windows 下将命令经 Bun 的 `-c` 包装交给 PowerShell，会加载用户 profile、打印 5.1 banner，行为异常
- **方案**：win32 且 shell 为 PowerShell 时，显式以 `-NoLogo -NoProfile -NonInteractive -Command` 调用；cmd.exe 走 Bun 的 `/d /s /c` 包装（已正常）
- **文件**：`packages/core/src/tool/bash.ts`
- **验证**：新增 3 个测试（构造断言 + 真实 PowerShell 执行），全部通过

## 高（影响重要功能）

### H1 — MCP 后代进程清理（Windows 枚举）
- **问题**：`pgrep` 在 Windows 不存在，MCP stdio 服务器关闭时孙进程成为孤儿，长期运行进程泄漏（`wmic` 已在新版 Windows 移除，不可用）
- **方案**：win32 下用 `Get-CimInstance Win32_Process` 单次导出 (pid, parent) 对，本地建树后 BFS 枚举全部后代
- **文件**：`packages/opencode/src/mcp/index.ts`
- **验证**：Effect 集成实测，后代枚举与清理通过（约 0.8s/次，清理路径可接受）

### H2 — git diff 的 `/dev/null` 平台化
- **问题**：`/dev/null` 是 POSIX 设备文件，非 MSYS 的 git 构建（如 MinGit）会解析失败，影响 untracked 文件 diff
- **方案**：`process.platform === "win32" ? "NUL" : "/dev/null"`（3 处）
- **文件**：`packages/core/src/git.ts`、`packages/opencode/src/git/index.ts`
- **验证**：`patchUntracked/statUntracked` 测试在 win32 通过

### H3 — abort() 杀进程树
- **问题**：`Process.spawn` 的 abort 仅杀直接子进程；Windows 下 SIGTERM→SIGKILL 升级无意义，派生的子进程泄漏
- **方案**：win32 下 abort 改走已有的 `stop()`（`taskkill /pid <pid> /T /F` 杀整树）
- **文件**：`packages/opencode/src/util/process.ts`
- **验证**：孙进程树实测全部清理

## 中（功能降级或静默失败）

### M3 — LSP 安装文件操作 Windows 重试
- **问题**：Windows 下杀毒/索引服务短暂锁定新下载文件，`fs.rm`/`fs.rename` 偶发 EBUSY/EPERM 导致 LSP 安装失败
- **方案**：提取通用重试函数 `Filesystem.withRetry`（win32 50 次 / 其余 5 次，间隔 100ms），包裹 LSP 全部安装路径的 rm/rename；worktree 清理复用同一函数
- **文件**：`packages/opencode/src/util/filesystem.ts`、`packages/opencode/src/lsp/server.ts`、`packages/opencode/src/worktree/index.ts`
- **验证**：重试函数单测通过（瞬时失败后成功、耗尽后抛出）

### M4 — chmod 权限语义 ACL 加固
- **问题**：Windows 下 `chmod` 只切换只读位，凭据文件的 `0o600` 语义不生效
- **方案**：新增 `applyFileMode`（`packages/core/src/util/file-mode.ts`）——chmod 后，属主独占模式（如 0o600）best-effort 执行 `icacls /inheritance:r /grant:r "<用户>:(R,W)"` 收紧 ACL；接入 core `writeJson`/`writeWithDirs` 与 opencode `writeStream`，覆盖 auth / mcp-auth 凭据写入
- **文件**：`packages/core/src/util/file-mode.ts`（新增）、`packages/core/src/fs-util.ts`、`packages/opencode/src/util/filesystem.ts`
- **验证**：实测 0o600 后 ACL 从 4 条继承项收紧为仅当前用户；0o644 不受影响

### M1 — SIGUSR2 信号不可用（记日志）
- **问题**：`process.on("SIGUSR2")` 在 Windows 下注册成功但永不触发，主题热刷新/配置重载静默失效
- **方案**（按决策：仅记日志）：三处注册点在 win32 下跳过注册并打一次性 stderr 警告
- **文件**：`packages/opencode/src/cli/cmd/run/footer.ts`、`packages/opencode/src/cli/cmd/tui.ts`、`packages/tui/src/context/theme.tsx`

### M2 — SIGHUP 信号不可用（控制台关闭清理）
- **问题**：Windows 无 SIGHUP，关闭控制台窗口时 TUI 渲染器不清理、finalizer 不执行
- **方案**：`process.on("exit")` 兜底 + bun:ffi `SetConsoleCtrlHandler`（`JSCallback`）捕获 CTRL_CLOSE/LOGOFF/SHUTDOWN → `destroyRenderer`；带 isTTY + `GetConsoleWindow` 守卫，仅拦截关机等事件，不干预 Ctrl+C
- **文件**：`packages/tui/src/terminal-win32.ts`、`packages/tui/src/app.tsx`
- **验证**：FFI 安装/卸载实测成功；真实关窗场景需手动验证（见已知限制）

### M5 — clipboard 缺少 windowsHide
- **问题**：win32 下剪贴板调用 powershell.exe 时可能闪现控制台窗口
- **方案**：spawn 选项加 `windowsHide: true`
- **文件**：`packages/tui/src/clipboard.ts`

### M6 — 硬编码 `/tmp` 路径
- **问题**：Windows 下 `/tmp` 被解析为当前驱动器根目录下的 `\tmp`，调试/示例工作区插件不可用
- **方案**：改用 `os.tmpdir()` + `path.join()`
- **文件**：`packages/opencode/src/control-plane/dev/debug-workspace-plugin.ts`、`packages/plugin/src/example-workspace.ts`

## 低（边缘场景）

### L1 — clangd symlink 静默失败
- **问题**：Windows 下 `fs.symlink` 需管理员或开发者模式，`.catch(() => {})` 吞错
- **方案**：win32 改用 `fs.copyFile` 复制为 `clangd.exe`（别名仅为便利，复制无副作用）；POSIX 保持 symlink
- **文件**：`packages/opencode/src/lsp/server.ts`

### L3 — uninstall 探测 bash 配置文件
- **问题**：win32 下 `SHELL` 未设置时回退探测 `~/.bashrc` 等无意义路径
- **方案**：win32 且 `SHELL` 未设置时提前返回 null；显式设置 SHELL（如 Git Bash 环境）仍正常支持
- **文件**：`packages/opencode/src/cli/cmd/uninstall.ts`
