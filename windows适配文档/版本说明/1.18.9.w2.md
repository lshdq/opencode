## 概述

首个包含实质性 Windows 适配修复的构建版本，核心解决 **Windows 下子进程启动导致的无限挂起**问题，并建立 Windows 构建基础设施与适配工作流。

## 核心修复

### 修复 Windows 进程 spawn 无限挂起（`packages/core/src/cross-spawn-spawner.ts`）

**问题**：在 Windows 上，Bun 使用 overlapped stdio 时，`child_process` 的 `spawn`/`close` 事件可能不可靠地触发，导致 shell 工具在超时竞速尚未建立之前就无限挂起。

**方案**：三层防御，全部以 `process.platform === "win32"` 守卫，非 Windows 行为不变：

1. **Spawn 超时（30s）**：若 `spawn` 事件未触发，使 `Effect.callback` 失败返回，而非永久挂起
2. **Exit 宽限期（2s）**：`exit` 已触发但 `close` 未跟随（继承的管道句柄未关闭）时，强制完成退出信号 `Deferred`，使 `exitCode` 与 kill 路径得以继续
3. **Kill 等待超时（5s）**：为 `handle.kill` 与 scope finalizer 中的 `Deferred.await` 增加最终超时，确保 SIGKILL 兜底路径不会无限挂起

对应提交：`ddcad28203 fix(core): prevent infinite hang spawning processes on Windows`
