# opencode 1.18.9.w1 版本说明

- **版本**：`1.18.9.w1`（基准版本 `1.18.9` + 适配号 `1`）
- **基准**：upstream/dev v1.18.9（fork 点 `f720490219`，2026-07-30）
- **日期**：2026-07-30
- **状态**：fork 基线，未做实质性功能修改

## 概述

本版本为 Windows 适配（win-adapt）分支的起点：从官方上游 `anomalyco/opencode` 的 `dev` 分支 v1.18.9 处 fork，建立本地适配分支与 remote 布局，**尚未包含任何实质性功能改动**。

## 内容

- 自 upstream/dev v1.18.9（fork 点 `f720490219`）分出 `win-adapt` 分支
- 建立 remote 布局：`upstream` = 官方仓库（只读同步源）、`origin` = 个人 fork（推送目标）
- 确立维护纪律：定期同步上游、基于 fork 点锚定基准版本

## 版本方案说明

Windows 适配构建版本号为 `<基准版本>.w<适配号>`：

- **基准版本**：win-adapt 分支与 upstream/dev 的 merge-base（fork 点）处的上游版本，不随上游推进而变化（本分支为 `1.18.9`）
- **适配号**：每次 Windows 适配构建递增（`.w1`、`.w2`、`.w3`……）
